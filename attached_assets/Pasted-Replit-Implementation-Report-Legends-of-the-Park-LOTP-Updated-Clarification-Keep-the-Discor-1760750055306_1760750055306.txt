5) Implementation details / code guidance (copy-paste ready)

Sidebar button (React + Next.js / React Router)

// SidebarButton.jsx
import { useRouter } from 'next/router' // or react-router
export default function SidebarButton({ href, label }) {
  const router = useRouter();
  return (
    <button
      onClick={() => router.push(href)}
      aria-label={label}
      className="sidebar-button"
    >
      {label}
    </button>
  );
}

Important: Use router.push or <Link> — do not attach href="#" with preventDefault without navigation logic. Add console.log in handlers during QA to confirm click fired.

Bubble placement algorithm (simple canvas/CSS approach)
	•	Compute N avatars. For each avatar i (0..N-1):
	•	angle = (i / N) * 2π
	•	x = centerX + (radius * cos(angle))
	•	y = centerY + (radius * sin(angle))
	•	Use CSS transform translate(-50%,-50%) to center each avatar at (x,y).
	•	If N > 24, add a second ring with smaller radius and start offset, or cluster.
(We can provide a JS snippet on demand — but this algorithm is sufficient for the front-end devs to implement.)

6) Debug checklist (when “buttons do nothing”)
	1.	Open browser console → any JS errors? Fix exceptions first (often prevents hydration).
	2.	Confirm DOM element receives the click: add console.log('click') to handler; if nothing prints, check overlay/z-index or pointer-events.
	3.	Check CSS: pointer-events: none on wrapper blocks clicks.
	4.	Check that the JS bundle is loaded and hydrated (SSR → client-side hydration mismatch can block event listeners).
	5.	If using Next.js with Static Export, ensure client-side routing script is included, or fallback to <a href="/park/acacia">.
	6.	Ensure router.push or <Link> is used instead of preventing default anchor behavior.

⸻

7) Static-first & Replit cost minimization (exact steps)
	•	Build for static hosting (Next.js export or React build).
	•	.replit run command must serve static build/ (example below).
	•	Do not enable watchers or hot reload on production repls.
	•	Use Supabase client directly from browser — avoid a server process.
	•	Avoid background workers, cron jobs, or sockets on Replit.
	•	Lazy load avatars and images, generate srcset, and set reasonable max upload sizes (2MB).

.replit example

run = "npm run start:static"
build = "npm run build"

package.json:

"scripts": {
  "build": "next build && next export -o out",
  "start:static": "npx serve out -s -l 8080"
}
